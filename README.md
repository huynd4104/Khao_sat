# Khảo Sát

Trang web deployable cho Vercel, dựng bằng Next.js. Trang chính là bộ chọn nhóm khảo sát theo đúng UI/UX Warm Claymorphism từ ui-skill-system.

## Chạy local

```bash
npm install
npm run dev
```

## Deploy

Push lên GitHub rồi import vào Vercel. Next.js sẽ build trực tiếp từ root project này.# Khao_sat
